# lafoi-classic

The original La Foi Designs website (pre-upgrade baseline) — preserved for design comparison.

This is the codebase as it stood at commit `dafcaee` of `Mutombe/lafoi`, before the editorial redesign pass that brought Phosphor icons, Fraunces/Inter typography, HeroSlideshow carousels, glassmorphism, patterns, and the Products + Projects pages.

Compare with the current redesigned site at https://lafoi.onrender.com
